# CurConv Customer အက်ပ် — Windows မှ APK တည်ဆောက်ရန်

ဒီဖိုင်တွဲသည် **Customer/User အက်ပ်၏ Flutter project အပြည့်အစုံ** ဖြစ်ပြီး Admin အက်ပ်နှင့် သီးခြားစီဖြစ်သည်။

ပင်မစာမျက်နှာ၏ အပေါ်ဘက် မီးခိုးရောင် အကောင့်/အသုံးပြုခွင့် အခြေအနေအကွက်ကို ဖယ်ရှားထားသည်။ ညာဘက်အပေါ်ထောင့်ရှိ Menu ထဲတွင် **Account**, **Themes**, **Settings**, **About** ပါဝင်သည်။ Account မှ အကောင့်နှင့် အသုံးပြုခွင့်အချက်အလက်ကို ကြည့်နိုင်ပြီး Themes မှ အက်ပ်အရောင်နှင့် ကီးဘုတ်အရောင်ကို ရွေးသိမ်းနိုင်သည်။

## Windows မှ APK တည်ဆောက်နည်း

1. ZIP ကို Windows ကွန်ပျူတာတွင် သီးခြားဖိုင်တွဲတစ်ခုထဲ ဖြည်ပါ။ ဥပမာ `D:\CurConv_Customer_Windows`။
2. VS Code ကိုဖွင့်ပြီး **File → Open Folder** မှတစ်ဆင့် `CurConv_Customer_Windows` အဓိကဖိုင်တွဲကို ရွေးပါ။ `android` ဖိုင်တွဲကို သီးသန့်မဖွင့်ပါနှင့်။
3. VS Code ရှိ Terminal ကိုဖွင့်ပြီး project အဓိကဖိုင်တွဲထဲတွင် အောက်ပါ command များကို တစ်ကြောင်းစီ ရိုက်ပါ။

   ```powershell
   flutter pub get
   flutter build apk --release --target-platform android-arm64
   ```

4. APK ကို အောက်ပါလမ်းကြောင်းတွင် ရှာနိုင်ပါသည်။

   ```text
   build\app\outputs\flutter-apk\app-release.apk
   ```

## ကိုယ်တိုင် Customer အဖြစ် စမ်းသပ်နည်း

- ဒီအက်ပ်သည် Firebase project `curconvbackup-7709c` ၏ Customer Android app (`com.example.curconv`) နှင့် ချိတ်ဆက်ထားသည်။
- APK ကို Android ဖုန်းတွင် ထည့်သွင်းပြီး Customer ဝင်ရောက်စာမျက်နှာမှ **အကောင့်အသစ်ဖွင့်ရန်** ကိုရွေးပါ။ Email/Password အကောင့်အသစ်ဖွင့်နိုင်သလို Google ဖြင့်လည်း ဝင်နိုင်သည်။ Email အတည်ပြုရန် လိုအပ်ပါက Inbox နှင့် Spam ဖိုလ်ဒါများကို စစ်ပါ။
- ပထမဆုံး ဆာဗာနှင့် အတည်ပြုချိန်တွင် ထိုအကောင့်အတွက် ၇ ရက် စမ်းသုံးခွင့် စတင်သည်။ ထို့နောက် CurConv Admin အက်ပ်တွင် ပြန်စစ်ရန် ခလုတ်နှိပ်လျှင် Customer စာရင်းတွင် ပေါ်လာမည်။
- Firebase Console → Authentication တွင် Email/Password နှင့် Google ဝင်ရောက်မှုတို့ ဖွင့်ထားရမည်။ Firestore Rules တွင် Customer/Admin အတွက် နောက်ဆုံးပြင်ထားသော rules များကို Publish လုပ်ထားရမည်။
- ဒီ version တွင် Admin အက်ပ်က စက်စာရင်းဖတ်နိုင်ရန် Firestore Rules အသစ်ကို ထည့်ပေးထားသည်။ Firebase Console → Firestore Database → Rules တွင် project အတွင်းရှိ `firestore.rules` ဖိုင်တစ်ခုလုံးကို အစားထိုးထည့်ပြီး **Publish** လုပ်ပြီးမှ Customer/Admin APK အသစ်များကို သုံးပါ။ Rules မထည့်ရသေးလျှင် စက်မှတ်တမ်းကို သိမ်း/ကြည့်၍မရပါ။

## ဒီဗားရှင်းတွင် ပြင်ထားသော အချက်များ

- မှတ်တမ်းကတ်အတွင်းရှိ `Merchant စာရင်း` ခေါင်းစဉ်ကို နှစ်ချက်နှိပ်၍ သီးခြားပြင်ဆင်သိမ်းနိုင်သည်။ အပေါ်ဘားရှိ `Money Txn` သည် ပုံသေဖြစ်ပြီး ဘယ်တော့မှ မပြောင်းပါ။
- ပင်မစာမျက်နှာ၏ ဘယ်ဘက် ငွေလွှဲပုံအရွယ်ကို `.webp` ဖိုင်အမည်နှင့် ကိုက်ညီအောင် ပြင်ထားပြီး မူလရည်ရွယ်ထားသည့် ပုံအရွယ်အစား ပြန်ရစေသည်။
- Money Txn ဖျက်မုဒ်တွင် ဘယ်ဘက် ယွမ်၊ ဈေးနှုန်းနှင့် ကျပ်တန်ဖိုး ၃ ကော်လံကို တစ်စုတည်း အနီရောင်ဘောင်ဖြင့် ပြထားပြီး တစ်ကြိမ်နှိပ်လျှင် ထိုငွေလဲမှတ်တမ်း ၃ ခုလုံးကို အတူတကွ ဖျက်နိုင်သည်။
- ပင်မစာမျက်နှာရှိ ငွေလွှဲ၊ အမြတ်နှင့် ငွေထုတ်ပုံ ၃ ပုံကို ပုံရိပ်အရည်အသွေးမပြောင်းသော WebP ဖိုင်အဖြစ် ပြောင်းထားသည်။ မူလ PNG များမှာ project ထဲတွင် အရန်အဖြစ်ကျန်ပြီး APK ထဲသို့ WebP များသာ ထည့်မည်။ ပုံဖိုင်များ၏ စုစုပေါင်းအရွယ်ကို 2.5 MB ခန့်မှ 1.8 MB ခန့်သို့ လျှော့ထားသည်။
- `MMK to CNY` စာမျက်နှာရှိ ပမာဏဖြည့်ကွက်နှစ်ခုကို ပင်မစာမျက်နှာက ကွက်များနှင့် တူညီသောပုံစံသုံးထားသည်။
- `ယွမ် ရောင်းဈေး` ကွက်နှင့် ဈေးသိမ်းခလုတ်ကို တစ်တန်းတည်း၊ ပမာဏကွက်များ၏ အမြင့်နှင့် နီးစပ်စွာထားသည်။
- `Copy` ကတ်များ၏ အမြင့်နှင့် Copy ခလုတ်အရွယ်ကို လျှော့ထားသည်။
- ပင်မစာမျက်နှာနှင့် `MMK to CNY` စာမျက်နှာ၏ ငွေဈေးနှုန်းများကို သီးခြားစီ သိမ်းထားသည်။ တစ်မျက်နှာတွင် သိမ်းလျှင် တစ်ခြားမျက်နှာ၏ ဈေးနှုန်း မပြောင်းပါ။
- ဖုန်းမျက်နှာပြင်၏ နေရာမရွေးမှ ဘယ်/ညာသို့ တိုတိုလေး ပွတ်ဆွဲ၍ စာမျက်နှာပြောင်းနိုင်သည်။ အပေါ်/အောက်သို့ လှုပ်ရှားမှုကြီးသော ပွတ်ဆွဲချက်များကို စာမျက်နှာပြောင်းခြင်းအဖြစ် မယူရန် စစ်ထားသည်။
- ပမာဏကွက်ဘေးရှိ `✖` ကိုနှိပ်လျှင် ထိုကွက်တစ်ခုတည်းကိုသာ ရှင်းပြီး၊ ထိုကွက်ကို ဆက်ရေးနိုင်ရန် ဂဏန်းကီးဘုတ်အတွက် ရွေးထားသည်။
- Customer တစ်ဦး၏ Gmail/UID အောက်တွင် ဝင်ထားသော Android အက်ပ်တင်သွင်းမှု တစ်ခုချင်းစီ၏ ဖုန်းအမှတ်တံဆိပ်၊ Model၊ Android ဗားရှင်း၊ CurConv ဗားရှင်းနှင့် နောက်ဆုံးချိတ်ဆက်ချိန်ကို Admin က ကြည့်နိုင်သည်။ Admin စာရင်းထဲရှိ Customer တန်း၏ ဖုန်းပုံသင်္ကေတကို နှိပ်ပါ။
- ပင်မစာမျက်နှာအပေါ်က မီးခိုးရောင် Account/အခြေအနေတန်းကို ဖယ်ပြီး လုပ်ဆောင်ချက်များကို Menu ထဲတွင် စုထားသည်။
- အရင်က ခွင့်ပြုထားပြီး နောက်ဆုံးဆာဗာစစ်ချိန်မှ ၂၄ နာရီမကျော်သေးပါက အက်ပ်ပြန်ဖွင့်ချိန်တွင် ဖုန်းထဲသိမ်းထားသော ခွင့်ပြုချက်ကို အရင်စစ်ပြီး Calculator ကို ချက်ချင်းဖွင့်မည်။ ဆာဗာစစ်ဆေးမှုကို နောက်ကွယ်တွင် ဆက်လုပ်မည်ဖြစ်၍ စောင့်နေစဉ် အဝိုင်းလည်သည့် loading သင်္ကေတ မပြတော့ပါ။ ပထမဆုံးဝင်ခြင်း၊ စက်ထဲခွင့်ပြုချက်မရှိခြင်း သို့မဟုတ် ၂၄ နာရီကျော်ခြင်းတွင် အင်တာနက်ဖြင့် အရင်စစ်ဆေးရမည်။
- စက်အမှတ်အသားသည် အက်ပ်က ဖန်တီးသော ကျပန်း ID ဖြစ်သည်။ ဖုန်းနံပါတ်၊ IMEI၊ စက်အမှတ်စဉ်နံပါတ် သို့မဟုတ် ကြော်ငြာ ID မကောက်ယူပါ။ Customer အက်ပ်ကို အင်တာနက်ချိတ်ထားချိန် ဖွင့်ဝင်ရောက်သောအခါ အချက်အလက်များ Firebase တွင် အသစ်ပြင်ဆင်မည်။ Gmail တစ်ခုတည်းဖြင့် ဖုန်းနှစ်လုံးသုံးပါက ထို Customer ၏ အောက်တွင် စက်နှစ်လုံးပေါ်မည်။ ဖုန်းကို စက်ရုံထုတ်အခြေအနေ ပြန်ထားခြင်း သို့မဟုတ် အက်ပ်ကို ပြန်တင်ခြင်းကြောင့် တပ်ဆင်မှု ID အသစ်ဖြစ်နိုင်ပြီး စက်စာရင်းတွင် ထပ်ပေါ်နိုင်သည်။

## ရှိပြီးသားအက်ပ်နှင့် ဒေတာကို ကာကွယ်ရန်

ဒီ project ၏ Android app ID သည် `com.example.curconv` ဖြစ်ပြီး လက်ရှိ Customer အက်ပ်နှင့် တူသည်။ Windows မှ တည်ဆောက်သည့် APK သည် အခြား signing key ဖြင့် ထွက်လာနိုင်သောကြောင့် ဖုန်းတွင် ရှိပြီးသား APK ကို တိုက်ရိုက် အစားထိုးမရနိုင်ပါ။ **လက်ရှိအက်ပ်ကို မဖျက်ပါနှင့်**—ဖုန်းထဲတွင်သာ သိမ်းထားသော ဒေတာများ ပျောက်နိုင်သည်။ ဖြစ်နိုင်ပါက အခြားဖုန်းတစ်လုံး သို့မဟုတ် Android emulator ဖြင့် အရင်စမ်းပါ။ `App not installed` သို့မဟုတ် လက်မှတ်မကိုက်ညီကြောင်း ပေါ်လာပါက Cancel လုပ်ပြီး လက်ရှိအက်ပ်ကို မဖျက်ပါနှင့်။ Local ဒေတာနှင့် Cloud Backup ရှိကြောင်း အရင်အတည်ပြုပါ။

ဒီ APK သည် စမ်းသပ်ရန်အတွက် debug signing ဖြင့် တည်ဆောက်နိုင်သည်။ အများပြည်သူသို့ ဖြန့်ဝေမည့် နောက်ဆုံး release signing မဟုတ်သေးပါ။
